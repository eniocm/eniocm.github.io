rclone pessoal – Enio

Este é um cliente OAuth de uso pessoal, usado pelo programa rclone para que o proprietário desta conta acesse o próprio Google Drive a partir do seu computador.

Não é um serviço público: o único usuário é o próprio proprietário.

Personal, single-user OAuth client used by rclone so the owner can access their own Google Drive from their computer. Not a public service.
