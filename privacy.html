Política de Privacidade – rclone pessoal

Este aplicativo é usado exclusivamente pelo seu proprietário, por meio do programa rclone, para acessar o próprio Google Drive.

  • Dados acessados: arquivos e pastas do Google Drive do proprietário (escopo https://www.googleapis.com/auth/drive).
  • Uso: os dados são lidos e gravados apenas para sincronizar e montar o Drive no computador pessoal do proprietário.
  • Armazenamento: os dados ficam somente no Google Drive e no computador do proprietário. Nada é enviado a servidores de terceiros.
  • Compartilhamento: nenhum dado é compartilhado, vendido ou transferido a terceiros.
  • IA: nenhum dado é usado para treinar modelos de inteligência artificial.
  • Revogação: o acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

English summary: This personal, single-user app is used only by its owner, through rclone, to access the owner's own Google Drive (drive scope). Data stays in Google Drive and on the owner's computer, is never shared, sold or transferred to third parties, and is never used to train AI models. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
