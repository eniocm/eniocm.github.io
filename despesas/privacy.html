Política de Privacidade – Despesas

Este aplicativo Android é usado exclusivamente pelo seu proprietário, no próprio celular, para registrar as próprias despesas.

  • Dados acessados: Gmail do proprietário, somente para leitura (escopo gmail.readonly), a planilha indicada por ele (escopo spreadsheets) e notificações de apps financeiros no celular.
  • Uso: os e-mails são lidos apenas para obter valores e vencimentos de faturas e boletos. A planilha é lida e gravada para manter os gastos.
  • Armazenamento: os dados extraídos ficam no celular e na conta Google do proprietário. O conteúdo dos e-mails não é guardado.
  • Compartilhamento e IA: nenhum dado é vendido. Se o proprietário configurar a própria chave de API, dados de contas que não puderem ser lidas localmente e de gastos novos são enviados a um serviço de IA (Gemini ou DeepSeek), apenas para extrair valores ou sugerir categorias. O proprietário não usa esses dados para treinar modelos de IA.
  • Revogação e exclusão: o acesso pode ser revogado em myaccount.google.com/permissions. Desinstalar o app apaga os dados do celular.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

English summary: This personal, single-user app reads the owner's Gmail (read-only) to get amounts and due dates from bills, and reads and writes the spreadsheet the owner selects. Extracted data stays on the owner's phone and Google account, and is never sold. If the owner configures their own API key, data from some bills and new expenses is sent to an AI service (Gemini or DeepSeek), only to extract amounts or suggest categories. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
